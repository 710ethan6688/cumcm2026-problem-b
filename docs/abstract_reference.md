# 全国大学生数学建模竞赛（CUMCM）大奖论文写作与摘要规范指南

> 本指南基于 2024 年国赛 A 题（板凳龙）多篇国一/大奖优秀论文与典型反面案例深度复盘提炼而成，专供论文手在撰写摘要、正文分析及结果包装时参考。

---

## 一、 摘要黄金“八股”架构（段落规范）

摘要是评委评分的核心（往往决定 70% 的初筛命运），必须严格遵循以下段落结构：

```
[首段：总体背景与统领]
本文针对 [研究对象/问题核心]，基于 [核心物理/几何规律]，构建了 [统领模型名称]。采用 [核心算法集群]，对 [问题涉及的不同阶段/场景] 进行了深入研究与优化求解。

[主体段：针对问题一 至 问题五]
针对问题 X：构建 [XX 模型名称（加粗）]。
1. 【建模起点】：首先，基于 [XX 原理/坐标系]，推导 / 证明了 [关键前置条件]；
2. 【核心方法与算法】：接着，采用 [经典定理 / 核心算法名称（加粗）]，以 [目标] 为目标函数，建立以 [变量] 为决策变量的优化模型；
3. 【结果呈现】：最终计算求得 [关键标量解（加粗）]；对于大规模结果，明确标注 “详细数据见正文表 X 与附件 resultX.xlsx”。
4. 【闭环验证（可选）】：最后，对求解结果进行了 [灵敏度分析 / 误差检验 / 几何极限论证]。

[尾段：全篇验证总结]
各阶段结果均通过 [独立交叉验证方法]，各项参数严格满足 [实际物理与工程约束]。

[关键词]
关键词：[统领模型]  [专业计算几何定理]  [高级优化算法]  [核心决策方法]
```

## 二、 优秀大奖论文的核心得分点（正面清单 ✅）

1. **标量必写死，矢量必指路**
   - 单一数值（如时间、极值速度、最短距离、最佳遮蔽时长）必须精确到指定小数位（如 4~6 位），并**直接加粗**呈现在摘要中。
   - 复杂数组/参数矩阵切忌罗列，必须统一使用标准指路话术：`“具体数据详见正文表 X 及附件”`。

2. **专业数学与计算几何定理“挂名”**
   - 遇到常规判定时，尽量提炼为经典的计算几何或分析学定理，提升理论档次：
     - 碰撞/重叠判定 ➔ **分离轴定理 (SAT)** / **凸包相交测试**
     - 搜索空间收敛性 ➔ **Lipschitz 连续性** / **单峰性分析**
     - 极限约束判定 ➔ **反证法** / **几何极值定理**

3. **标准三要素陈述优化模型**
   - 优化问题必须规范化表达：`“以 [目标] 为目标函数，以 [约束] 为约束条件，建立以 [变量] 为决策变量的单目标/多目标优化模型。”`

4. **遇到“无能为力”或“算不出更好”时的绝杀话术**
   - **绝对不要**说“算法未找到更优解”或“第X项没有产生效果”；
   - **必须**使用客观几何/物理极限来论证：
     > `“通过几何投影/相切关系分析证明，在给定物理与动力学约束下，XX 已达理论极限，无法进一步增加/减小。”`

5. **遇到漏防/舍弃部分目标时的包装话术**
   - 不吹嘘花哨战略，使用客观的“最优化代价选择”：
     > `“受限于空间几何距离与拦截时间窗口，强行覆盖次要目标会导致全局目标函数大幅劣化。因此算法在全局最大化准则下，自动趋向于集中资源保障主要威胁方向。”`

## 三、 典型扣分与低级失误（反面避坑清单 ❌）

1. ❌ **严禁机械重复抄题**：
   - 绝对不要在摘要的多个段落中反复抄写题目的采样点（如“并将 0s, 60s, 120s... 节把手数据填入表X”）。这属于恶意水字数，严重扣印象分。
2. ❌ **严禁写出“偷懒”话术**：
   - 绝对不要写 `“为了简化计算，我们仅考虑...”`（会被评委视为偷工减料导致模型失真）；
   - 正确写法是 `“利用反证法/单调性分析严格证明了最危险区域必位于...，由此合理缩小搜索空间。”`
3. ❌ **严禁口语化词汇**：
   - 避免使用 `“猜想”`、`“大概”`、`“感觉”` 等词汇，改用 `“通过数值实验发现”`、`“基于单峰性分析”`。
4. ❌ **避免使用通识课级别关键词**：
   - 关键词尽量避开 `“仿真模拟”`、`“微元法”`、`“二分法”` 等大一通用词，换为具体的算法名与模型名（如 `“带重启CMA-ES”`、`“自适应差分进化”`）。

## 四、 高频黄金替换词库

| 常见/不当表述 | 大奖论文规范表述 |
| :--- | :--- |
| 第三发弹没有产生增量 | 经几何投影证明，遮蔽面积已达理论上限，无法进一步增加 |
| 放弃了 M3 导弹的拦截 | 受空间时序窗口限制，模型算法自动趋向于集中资源于高收益方向 |
| 敏锐地揭示了 | 通过数值计算与几何分析证明了 |
| 算出来的答案很精准 | 误差严格控制在 $10^{-4}$ 精度范围内 |
| 完美无缝衔接 | 遮蔽区间互不重叠，呈现接力特征 |
