# 2026 年数学建模国赛选题分析（Codex 新版）

- 生成日期：2026-09-10
- 分析范围：A、B、C 题；按团队要求不分析 D、E 题
- 当前结论：**第一推荐 C 题，备用 B 题，A 题暂不优先**

## 1. 已读取材料与证据边界

本次分析读取了 A、B、C 三道题的 Markdown 转写稿，并核对了对应附件清单；定向抽查了 A、C 题的 Excel 数据结构，以及 B 题模拟器使用说明和 HTTP+JSON 接口规则。原 PDF 是题面权威版本，正式开题时应针对公式、表格和转写疑点回查 PDF。

本报告只用于选题，不锁定后续模型、算法和论文结构。当前尚未全面清洗数据、运行优化模型或连接 B 题模拟器，因此对完成难度和深化空间的判断属于基于题面与附件结构的分析，而不是已经完成的试做结果。

## 2. 三道题概览与初筛

| 题目 | 主要任务 | 数学与实现特征 | 初筛判断 |
| --- | --- | --- | --- |
| A 题：药材的烘干问题 | 建立温度与水分浓度的时空演化模型，计算烘干时间，并处理药材收缩后的移动边界 | 传热传质机理、非线性扩散、变物性、偏微分方程数值求解 | 有研究深度，但与团队优化准备方向匹配较弱，暂不优先 |
| B 题：无线电干扰源定位与清除 | 计算定位区域、设计检测点、自动搜索并清除全向及定向干扰源 | 几何定位、在线搜索、路径规划、模拟器闭环测试 | 研究与算法空间较大，但外部模拟器和完整清除保障带来交付风险，作为备用 |
| C 题：微网与外部电网电力调控 | 制定计划购电、紧急购电、滚动调整与波动电价下的储能调度策略 | 时序预测、储能状态递推、线性或混合整数优化、滚动决策 | 优化目标清楚、数据规整、结果可复算，与团队方向最匹配，进入第一推荐 |

## 3. 重点候选比较

### 3.1 C 题：可靠完成下限较高

C 题四问始终围绕购电量、储能充放电量、储电状态和总费用展开。问题一可形成确定条件下的日内调度基线；问题二加入负载与光伏变化及紧急购电；问题三利用 0:00、6:00、12:00、18:00 的预报进行滚动调整；问题四再引入实时波动电价。四问具有自然递进关系，前问模型和代码能够被后问扩展。

即使预测方法或高级策略没有形成明显优势，团队仍可采用可解释的基础预测与滚动调度方案，完成全部小问并形成完整论文。附件结构也支持自动化处理：单日数据按 10 分钟排列，全年负载、光伏和电价为规则矩阵，预报表对应每日四次、每次未来 24 小时的预测。抽查中未发现必须大量人工标注或外部搜集数据的迹象。

C 题最大的风险是信息边界与结算口径。每天 0:00 制定计划时，不能使用当日尚未发生的真实负载、真实光伏或未来电价，否则会产生信息泄漏；多次调整的计费基准、跨日储电状态以及充放电效率的计量位置，也必须在建模前统一。只要这些定义得到正确处理，目标函数、约束和费用都可以独立复算，便于及时发现错误。

### 3.2 B 题：上限高，但交付依赖更强

B 题兼具几何推理和在线决策。定位区域收缩、第二检测点选择、频道扫描、搜索路线以及发现新目标与追踪已知目标之间的权衡，都能直接影响任务时间，具有较强的差异化空间。

其主要风险集中在问题三、四。干扰源总数未知，程序必须判断何时已经完成搜索；定向源可能因发射方向导致近处检测仍返回无信号，因此单次无信号不能排除附近存在目标。同一地点重复检测也不能消除固定环境误差。除算法正确外，还必须完成模拟器在线登录、接口容错、充分演练、六次正式测试和日志交付。

B 题存在保守搜索覆盖与可靠定位清除的基础路线，但本次尚未验证其覆盖性、运行时间和模拟器接入状态。因此，只有团队在开局阶段快速完成模拟器连通，并证明定向源搜索具有可靠退路时，才建议将 B 题提升为首选。

### 3.3 A 题：机理和数值门槛决定成败

A 题的数据规模较小，人工清洗不是主要负担。真正困难在于温度与水分的耦合、含水率相关扩散系数、变物性和药材收缩引起的移动边界。题目要求输出密集时空结果并保留四位小数，因此数值稳定性、边界条件和误差控制比单纯生成结果更加重要。

如果队内有人熟悉传热传质、守恒方程和移动边界数值方法，A 题可以形成扎实论文；在当前已知的优化建模准备方向下，它需要额外补足机理推导与数值验证，可靠完成成本高于 C 题。

## 4. 第一推荐：C 题

推荐 C 题的决定性理由是：它把团队擅长的优化建模直接放在题目核心，同时具备较高的可靠完成下限、清晰的四问递进关系和可复算的证据链。模型效果可以通过能量守恒、储能边界、紧急购电量、费用分解和同口径策略对比检验，Agent 也能够高效承担数据索引核对、优化实现、全年回测、独立复算和结果表生成。

选择 C 题的主要代价是需要处理时间序列预测和滚动决策，且必须严格遵守决策时可获得的信息。预测误差最小不一定意味着购电成本最低，因此论文不能只停留在预测指标，还要解释误差如何通过紧急购电和调整费用影响最终决策。

## 5. 备用题：B 题及转用条件

B 题作为备用。若开局核查同时满足以下条件，可重新考虑将其升为首选：

1. 官方模拟器可以稳定登录，四类接口均能成功调用并正确记录日志；
2. 团队能提出面对未知目标总数的可靠停止或覆盖判据；
3. 对定向源的无信号歧义有可执行的搜索退路；
4. 多轮演练表明全部清除能够稳定实现，现实运行时间满足正式测试限制。

若其中任一项无法在选题阶段快速确认，继续选择 C 题更稳妥。

## 6. C 题最值得继续研究的方向

1. **信息约束下的调度**：明确每次决策实际可用的数据，建立无信息泄漏的顺序回测。
2. **预测误差与决策损失联动**：比较预测精度与实际购电费用，刻画低估导致的五倍紧急购电风险。
3. **滚动预报的边际价值**：量化 6:00、12:00、18:00 更新带来的节费收益与调整成本，直接回答问题三是否需要其他时刻预报。
4. **储能跨时段与跨日状态**：保证能量守恒、效率口径和储电边界一致，避免通过透支后续状态获得虚假低成本。
5. **独立费用复算**：将策略生成器与评价器分开，逐项核验计划、调整、紧急购电及违约费用。

## 7. 可能改变推荐的最小核查

在正式锁定题目之前，建议进行两项低成本核查：

- 对 C 题逐字确认各决策时刻的信息集合、调整购电结算方式和后续日期的储电状态规则，并完成一个代表性日期的可行调度测试；
- 对 B 题完成模拟器登录与接口冒烟测试，再以少量演练检查定向源搜索和任务停止逻辑。

如果 C 题的关键计费口径存在无法消除的歧义，或全年滚动求解在现有环境中无法稳定运行，而 B 题模拟器已经连通并具有可靠的全部清除策略，则推荐可以转向 B 题。就当前材料而言，仍以 **C 题为第一推荐**。
