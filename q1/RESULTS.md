# B 题 Q1 第一版实现验证结果

## 1. 当前结论

第一版 Python 实现已经闭合 Q1 的正式计算链，并在当前验证范围内通过。正式顶点路线为角度排序双端队列半平面交，复核路线为边界线两两求交后全约束筛选；正式直径路线为旋转卡壳，复核路线为全部顶点对穷举；覆盖结论分别用点积式和圆心距离式计算。

本结果只能支持“实现通过当前解析、差分和性质验证”，不能表述为算法已经对所有浮点临界输入得到形式化证明。题目没有给出固定数值实例，因此本文件也不报告官方实例数值答案。

## 3. 已执行验证

### 3.1 解析与边界测试

共执行 15 个单元测试，全部通过。覆盖内容包括：

- $0/2\pi$ 方向接缝及前向性；
- 正方形正常定位区域；
- 空平行约束、无界楔形、无界条带；
- 退化线段与退化单点；
- 同向冗余和重复约束；
- 正三角形不覆盖反例与矩形覆盖例；
- 观测顺序、重复约束及刚体变换不变性；
- 验证模式与跳过独立复核的正式快速模式。

### 3.2 固定种子差分与性质验证

结构化摘要见 [`results/q1_verification.json`](results/q1_verification.json)。1000 个随机正常实例全部返回 `VALID`，且全部满足：

- 生成真源位于所有测向角域内；
- 主半平面交与独立交点枚举一致；
- 旋转卡壳与全顶点对穷举的直径一致；
- 点积覆盖式与圆心距离覆盖式一致；
- 1000 次观测顺序检查通过；
- 1000 次重复约束检查通过；
- 8443 次增加约束后的直径单调性检查通过；
- 100 次平移与旋转不变性检查通过；
- 50 次容差敏感性检查通过。

1000 个合成实例中有 347 个被相应直径圆盘覆盖、653 个未被覆盖。这一比例只描述验证生成器产生的合成样本，不能解释为题目场景中的覆盖概率，也不用于论文主结论。

本次 1000 例验证总用时约 4.6 秒，包含独立复核和多项重复性质检查；它不是只运行正式主算法的性能基准。

## 4. 当前边界

- 正常随机样本刻意让检测点环绕真实源，不代表题目中所有可能的检测点布局分布。
- 空、无界和退化状态已经由解析实例检查，但极端近似平行、超大动态范围和任意高精度复算尚未形成穷尽性证据。
- `NUMERICALLY_UNCERTAIN` 是防止临界输入被伪装为正常结果的保护状态，不等于所有临界浮点情形均已被完全分类。
- 当前结果由 AI 辅助实现与验证；所有命令、随机种子和结构化摘要均已保留，可由团队独立复跑。
