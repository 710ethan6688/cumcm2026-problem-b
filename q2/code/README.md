# Q2 代码

本目录包含 `METHOD.md` 中的低分辨率单点原型，以及建立在完整嵌套网格上的**多分辨率数值候选带**。后者输出具有非零面积和明确边界的方形单元并集，不再把候选区域误写成若干零面积点；它仍不是连续空间严格求解器。

## 已实现

- 第一次观测后的角域—距离状态域离散，并区分正面积状态与零面积退化状态；
- 第二检测点的 `near`、`direction`、`no_signal` 三分支；
- 复用 Q1 半平面交求解器计算纯角域交会直径；
- 给定接收半径下保留全部采样直径断点的经验阶梯曲线，以及稳健点态下包络；固定的 8 个直径阈值只作为输出摘要，不参与点间支配；
- 通过极坐标径向交段和自适应积分计算有效覆盖率 `G` 与近场覆盖率 `H`，避免 5 m 近场被均匀源点采样漏掉；
- 采样版 `Gamma`；
- 基于极坐标单元覆盖和 2-Lipschitz 上界的 `Gamma` 符号认证；
- 基于曲线、`G`、`H` 的近似全局非劣前沿，以及采样安全点内部前沿；
- 三级嵌套候选、源域、接收半径和角度网格，并比较前沿 Hausdorff 距离及共同候选的曲线、G、H变化；
- 全局候选带、安全内部候选带及二者交集的连通分量、面积、包围盒和边界线段；
- JSON 结构化输出与单元测试。

若第一次观测只留下零面积退化状态，入口会返回 `DEGENERATE_INPUT_NO_AREA_CURVE`，保留逻辑相容半径信息，但不伪造面积比例或候选前沿。

## 证据边界

当前版本仍对源位置上的交会直径、接收半径、第二示向角和候选点进行离散评价；分支面积 `G/H` 已改为自适应几何积分。因此：

- `sampled_safe=true` 仍只表示采样判断；正式安全性必须读取 `gamma_certificate.status`。只有 `CERTIFIED_SAFE` 才表示其 Lipschitz 上界不大于零；
- 前沿仍是候选网格上的数值前沿，不是连续候选空间的完整 Pareto 前沿；候选带中的每个单元也不表示其中每一点均已证明非劣；
- 候选包围网格由状态域边界固定，不随径向积分分辨率漂移；原型阶段不按采样点提前剪除候选单元；
- 曲线在当前源状态离散下保留全部有限断点，但仍是点估计，尚未实现 METHOD 中的横向/纵向误差包络和连续 `R` 区间覆盖；
- 角度表步长若大于完整误差区间宽度会自动收紧，但仍只是误差区间内的离散上确界近似；
- 单点原型和三级候选带均不得直接作为论文正式结果表；正式使用还需要连续接收半径和横纵误差包络验证。
- 多分辨率程序完整评价每一级包围网格，没有利用粗层中心值删除细层点；因此不会把点支配误当成连续单元支配。

## 运行

在本目录执行：

```powershell
python -m unittest discover -s tests -v
python run_q2_prototype.py
python run_q2_regions.py
python run_q2_validation.py --profile quick
```

第二条命令写出带 UUID 的单点诊断 JSON；第三条命令默认使用 500/250/125 m 三级联合分辨率；第四条命令批量验证六类代表场景并为每次运行建立独立目录和 `index.json`。正式配置使用 `python run_q2_validation.py --profile formal`。

默认命令使用 25 个源角单元、24 个径向单元、9 个接收半径节点和 1° 第二示向表步长。默认的 `A=(0,0)`、第一次示向 0° 只是演示输入，并非题面给出的官方数值实例；正式分析必须显式传入研究场景。

快速冒烟测试可降低分辨率：

```powershell
python run_q2_prototype.py --angle-cells 5 --radial-cells 4 --radius-count 3 --candidate-step 1000 --angle-step-deg 5
```

默认物理参数来自题面：目标圆半径 1800 m、示向误差 ±1°、近场阈值 5 m、接收半径区间 1000–1500 m。第一次检测点、第一次示向及目标圆圆心均可通过命令行参数覆盖。

## 文件职责

- `q2_geometry.py`：几何基础与 Q1 求解器适配；
- `q2_state.py`：第一次观测状态域、接收半径网格和候选点网格；
- `q2_measures.py`：三分支面积的极坐标自适应积分；
- `q2_curve.py`：完整采样阶梯曲线、稳健下包络和全断点支配；
- `q2_evaluator.py`：整合单点评价、近似支配与代表点；
- `q2_safety.py`：严格覆盖意义下的 `Gamma` 上下界与安全状态认证；
- `q2_regions.py`：网格前沿扩张、方形单元并集、连通分量和多分辨率比较；
- `run_q2_prototype.py`：批量候选计算和 JSON 输出入口；
- `run_q2_regions.py`：多分辨率数值候选带输出入口；
- `run_q2_validation.py`：第四阶段多场景收敛验证与独立运行索引入口；
- `tests/`：几何边界、退化状态与评价器不变量测试。
